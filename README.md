# Daily Investment Banking Brief

A mobile-friendly archive of the most consequential daily investment-banking news, written for quick scanning.

## Reading order

1. **At a glance** — the day's headline transaction and financing figures.
2. **Story mix** — a simple count of M&A, equity, debt, restructuring and market stories.
3. **Decision table** — what happened, the key number, the transaction stage and a cautious beginner takeaway.

The website reads its archive from `data/briefs.json`. Each future edition should be appended as a new object at the top of that array; the newest date is selected automatically.

This is educational information, not personalised investment advice.
